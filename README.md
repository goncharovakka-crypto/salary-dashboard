# 💰 Зарплаты в России: номинальные и реальные (2017–2025)

Интерактивный дашборд на Streamlit: динамика зарплат по видам экономической деятельности в России с учётом инфляции.

**🔗 Работающий сервис:** https://salary-dashboard-mxyhuapnh2balaterfastj.streamlit.app/

**👤 Автор:** Екатерина

## Описание датасета

- **Зарплаты** — среднемесячная номинальная начисленная заработная плата работников организаций по видам экономической деятельности (рублей), годовые данные 2017–2025, 19 видов деятельности + среднее по отраслям (классификация ОКВЭД2). Файл: `data/wages.csv`.
- **Инфляция** — годовая инфляция в России, декабрь к декабрю, % (2017–2025). Файл: `data/inflation.csv`.
- **Макропоказатели** (для дополнительного исследования) — рост ВВП, безработица, ВВП на душу населения; загружаются из API Всемирного банка по кнопке в приложении.

## Источники данных

- Росстат, «Рынок труда, занятость и заработная плата»: https://rosstat.gov.ru/labor_market_employment_salaries
- Таблицы уровня инфляции в России: https://уровень-инфляции.рф/таблицы-инфляции (по данным Росстата)
- Всемирный банк, открытые данные: https://data.worldbank.org

## Что умеет приложение

- 📈 линейный график динамики (номинальные и реальные зарплаты, индекс, логарифмическая шкала);
- 📊 столбчатый график: номинальный рост, инфляция и реальный рост по годам;
- 🏆 рейтинг видов деятельности по росту зарплаты за период;
- 🔍 дополнительное исследование: корреляция реальных зарплат с безработицей, ВВП (кнопка загрузки данных);
- элементы интерфейса: фильтры (multiselect, slider, radio, checkbox, toggle, selectbox), кнопки сброса и загрузки, скачивание данных в CSV.

**Методика.** Реальная зарплата = номинальная / индекс цен (база — первый год выбранного периода).
Реальный рост к предыдущему году = (1 + номинальный рост) / (1 + инфляция) − 1.
